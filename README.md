# 八万·蚊消令 — 智能灭蚊生态APP

> 全球首款以电蚊拍为硬件入口、打通全穿戴设备、游戏化竞技驱动留存的智能灭蚊生态平台。

## 在线体验

🔗 **Netlify**: [mosquito-kill-pro.netlify.app](https://mosquito-kill-pro.netlify.app)  
🔗 **Vercel**: [mosquito-kill-pro.vercel.app](https://mosquito-kill-pro-1702987310-6727s-projects.vercel.app)

## 功能概览

- ⚡ 实时击杀计数 — 蓝牙连接电蚊拍，精准计数+动画反馈
- 🎮 **极速灭蚊** — 10秒倒计时点击游戏，蚊子随机出现，速度递增
- 🏆 排行榜 — 赛季制竞技排名 + 游戏极速榜，金银铜牌标识
- 📡 设备管理 — BLE扫描配对，电量/状态实时监控
- 🎖️ 成就系统 — 8枚勋章，铜/银/金/传说四档分级
- 👤 个人主页 — 战绩统计、历史记录、会员入口

## 游戏玩法

🦟 点击第6个Tab **「🎮 游戏」** 进入极速灭蚊模式：
- 10秒倒计时，蚊子随机出现在游戏区域内
- 点击蚊子即可击杀，带消失动画 + 音效反馈
- 倒计时越接近0，蚊子生成速度越快（900ms → 180ms）
- 未击杀的蚊子2秒后自动飞走
- 游戏结束后显示成绩 + 模拟榜单排名
