# 八万·蚊消令 — 智能灭蚊生态APP

> 全球首款以电蚊拍为硬件入口、打通全穿戴设备、游戏化竞技驱动留存的智能灭蚊生态平台。

## 在线体验

🔗 [Vercel 部署链接]()

## 功能概览

- ⚡ 实时击杀计数 — 蓝牙连接电蚊拍，精准计数+动画反馈
- 🏆 排行榜 — 赛季制竞技排名，金银铜牌标识
- 📡 设备管理 — BLE扫描配对，电量/状态实时监控
- 🎖️ 成就系统 — 8枚勋章，铜/银/金/传说四档分级
- 👤 个人主页 — 战绩统计、历史记录、会员入口

## 技术栈

- 前端：HTML5 + CSS3 + Vanilla JS（SPA）
- 设计：深色主题 #0A0E1A，品牌色 #F59E0B（荧光琥珀橙）
- 字体：system-ui + Courier New（数字等宽）
- 图标：纯CSS/SVG，无外部依赖
- 部署：Vercel（静态站点）

## 本地开发

```bash
# 直接用浏览器打开
open index.html

# 或用任意静态服务器
npx serve .
```
